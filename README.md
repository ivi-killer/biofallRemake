# BioFall

BioFall es un roguelike de supervivencia 2D con perspectiva cenital (top-down), ambientado en un mundo hostil y cambiante. Explora biomas como bosques, laberintos y laboratorios abandonados, consigue recursos, construye defensas y adapta tu estrategia para sobrevivir. El juego combina exploración, combate y progresión con una identidad visual minimalista, y está diseñado para jugarse tanto en PC como en dispositivos móviles.
